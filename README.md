<h1>📚 Book Store MERN Stack Project</h1>

<p>
  Welcome to the <strong>Book Store</strong> MERN Stack Project! This full-stack application allows users to <em>create, read, update, and delete books</em> using the latest web development technologies including <strong>MongoDB, Express.js, React.js, and Node.js</strong>.
</p>

<hr>

<h2>🚀 Tech Stack</h2>
<ul>
  <li><strong>Frontend:</strong> React.js, Vite, Tailwind CSS</li>
  <li><strong>Backend:</strong> Node.js, Express.js</li>
  <li><strong>Database:</strong> MongoDB (via Mongoose)</li>
  <li><strong>Routing:</strong> React Router DOM</li>
</ul>

<hr>

<h2>🎯 Features</h2>
<ul>
  <li>Add new books to the store</li>
  <li>View a list of all books</li>
  <li>View detailed information about a book</li>
  <li>Edit book details</li>
  <li>Delete a book</li>
  <li>Responsive design with clean UI</li>
  <li>Modal popups for better user experience</li>
  <li>Stylized alerts and confirmation messages</li>
</ul>




<hr>

<h2>⚙️ Installation Guide</h2>

<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/muneeb-shafique/Book-Store-MERN-Stack/</code></pre>
  </li>
  <li>Install server dependencies:
    <pre><code>cd server<br>npm install</code></pre>
  </li>
  <li>Install client dependencies:
    <pre><code>cd ../client<br>npm install</code></pre>
  </li>
  <li>Start the development server:
    <pre><code>npm run dev</code></pre>
  </li>
  <li>Ensure MongoDB is running locally or provide Atlas connection in <code>.env</code></li>
</ol>
